# 欢迎来到申论学习笔记

这是一个用于收集、整理和学习申论相关文章的知识库。

## 📚 使用说明

本站点主要用于：

- **收集官媒文章**：从人民日报、新华社、光明日报等官方媒体收集优质文章
- **文章拆解分析**：对文章的结构、论点、论据、修辞手法等进行详细分析
- **学习笔记**：记录学习心得和写作技巧
- **素材积累**：整理可用于申论写作的名言警句、案例素材等

## 🗂️ 内容组织

文章按以下方式分类：

- **时政热点**：最新的时事政治文章
- **五位一体**：经济、政治、文化、社会、生态文明建设相关文章
- **写作技巧**：申论写作方法和技巧
- **经典范文**：优秀申论范文和官媒评论

## ✍️ 如何添加文章

1. 在 `docs` 目录下创建对应分类的文件夹
2. 创建 Markdown 文件（`.md` 或 `.mdx`）
3. 添加文章内容和分析
4. 提交到 GitHub，自动部署

详细说明请查看后续章节。
